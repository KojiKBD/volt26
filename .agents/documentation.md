# Documentation Rules

- Maintain project documentation in English.
- Treat `docs/simply-love-functional-inventory.md` as the living map of non-visual Simply Love functionality relevant to VOLT26.
- Update the functional inventory whenever a Simply Love feature is assessed, adopted, replaced, intentionally omitted, or synchronized.
- Record behavior separately from presentation. A feature that includes both must document its behavioral responsibility independently of its graphics.
- Document the upstream Simply Love version or commit used for every completed synchronization review.
- Keep migration decisions traceable by recording the relevant VOLT26 branch, implementation location, and verification status.
