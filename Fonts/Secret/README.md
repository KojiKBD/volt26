# Hidden song lyrics font

`_secret lyrics fill` / `_secret lyrics edge` (redirected as `Secret Lyrics
Fill` and `Secret Lyrics Edge`) are the lyrics font of the hidden song
(`BGAnimations/ScreenGameplay underlay/Secret.lua`, see `docs/hidden-song.md`).
They are generated by `tools/secret/build_lyrics_font.py` from Archivo
(wght 900, wdth 62), under the SIL Open Font License 1.1 (`OFL-archivo.txt`).
The pages are regenerated, not edited.
