# Cutout lettering faces

Bitmap fonts used by `VOLT26.Cutout` (`Scripts/VOLT26_Cutout.lua`). They are
generated by `tools/cutout-fonts/generate.py` from these typefaces, all under
the SIL Open Font License 1.1 (licence texts alongside, `OFL-*.txt`):

| Face id    | Typeface       | Instance         | Stands in for                  |
| ---------- | -------------- | ---------------- | ------------------------------ |
| tinos      | Tinos          | Bold             | Times New Roman                |
| caprasimo  | Caprasimo      | Regular          | Cooper Black                   |
| spartan    | League Spartan | wght 700         | ITC Avant Garde Gothic         |
| besley     | Besley         | wght 800         | Clarendon                      |
| jost       | Jost           | wght 700         | Futura                         |
| archivo    | Archivo        | wght 800, wdth 100 | Helvetica Now Display        |

Sources: the google/fonts repository (`ofl/<family>/`). The pages are
regenerated, not edited; see the generator for the character set and em size.
